Project goal

A Socratic tutor, not an answer key.

An AI-powered math tutor for groep 7-8 (HAVO-track) students, built to help them practice independently after school.

  • Diagnose where a student's reasoning breaks down, step by step — not just whether the final answer is right.
  • Respond with guiding hints, never the direct answer.
  • Read real handwritten work: ink strokes in, recognized LaTeX steps out.
  • Status: trial / experiment — free-tier tooling and minimal cost prioritized everywhere unless a decision says otherwise.

Team03 / 09
Scope

What "1st MVP" actually means.

In scope
  • Handwritten step input → recognized LaTeX, with Confirm/Edit before checking
  • Real problem bank — 47 seeded groep 8 problems
  • Per-step correctness checking (parser + canonical-form evaluator)
  • Generic Dutch-language hint on any wrong step
  • Attempt persistence, deployed live end-to-end
Deferred to 2nd MVP
  • Misconception-specific rule matching — every wrong answer gets the same generic hint for now
  • LLM-generated hints — static Dutch text only
  • Full rekenen-domain coverage — problem bank is groep 8 only so far

Decided deliberately on 2026-08-03 — not a gap, a sequencing call.
